# Livros — fluxo Base-first

Pasta-irmã de `apostilas/`. Aqui entram as **obras primárias de Jan Val Ellam** reprocessadas no fluxo moderno (camadas → leitura → dossiê → **Devolutiva** → ampliações).

## Convenção (aprovada na abertura da Fase 1, 2026-08-23)

| Pasta | Papel |
|---|---|
| `livros/B0NN_slug/` | ciclo em andamento (PDF + extract + ficha + analise/) |
| `livros/CONCLUIDOS/` | só depois da Devolutiva **e** da apostila/tratado do livro |

O nome da raiz é **minúsculo** (`livros/`), no padrão de `apostilas/`, `termos/`, `pedagogico/`. `CONCLUIDOS` fica no masculino (livro).

## O que nunca vai para cá

- Palestras e lives → `apostilas/`
- Materiais do curador (ART) → `apostilas/CONCLUIDAS/` (já é o hábito)
- Terceiros (EXT) → `materiais_externos/`
- Glossário Raquyel (B031) → fonte **secundária**; não reprocessar como primária
