## 2. Status do termo

`⚪ candidato` → `🟡 provisório` → `🟠 em análise` → `🟢 verificado`

(Definições e critérios em `01-ficha-modelo.md`, seção 3.)

## 3. Tipos de relação

| Tipo | Uso |
|---|---|
| `é-um` | hierarquia / subtipo |
| `parte-de` | composição |
| `criado-por` | autoria / origem |
| `envolve` | participação de ser/entidade |
| `ocorre-em` | local / contexto |
| `ocorre-após` / `ocorre-antes` | sequência temporal |
| `associado-a` | afinidade geral |
| `opõe-se-a` | antagonismo |
| `sinônimo` / `variação` | mesma entidade, outra grafia/nome |
| `tema-de` / `anunciado-em` | vínculo termo ↔ obra |

## 4. Siglas de obras

- Formato: `B###` (ex.: `B001` = *O Drama Cósmico de Javé*).
- Cadastro completo em `03-bibliografia.md`; siglas **não se reaproveitam**.
