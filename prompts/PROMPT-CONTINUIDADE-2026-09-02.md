## 🔧 FLUXO DE PROCESSAMENTO USADO

### Esteira Leve (4 fases)

1. **FASE 1 — Garimpo**
   - Ler o arquivo `original.txt` completo
   - Identificar 25 pérolas principais
   - Criar `ciclo.toml` com metadata
   - Criar `pacote_P2024-XX-XX.txt` com as pérolas
   - **Commit:** `P2024-XX-XX: FASE 1 — ciclo.toml + pacote de garimpo`

2. **FASE 2 — Devolutiva**
   - Apresentar devolutiva ao usuário
   - Aguardar aprovação do garimpo
   - Validar citações byte-exatas no original
   - Criar `ampliacoes.md` com citações validadas
   - **Commit:** `P2024-XX-XX: FASE 2 — arquivo de ampliações`

3. **FASE 3 — Aplicação (Ampliações)**
   - Aplicar ampliações nas fichas existentes (inserir seção `## Ampliação — P2024-XX-XX`)
   - Adicionar fonte P2024-XX-XX nas fichas (seção `## Fontes`)
   - **Commit:** `P2024-XX-XX: FASE 3 — ampliações aplicadas`

4. **FASE 4 — Códigos Novos**
   - Criar novas fichas (RC-XXX-nome.md)
   - Atualizar `ciclo.toml` com `termos_novos` e `delta_esperado`
   - **Commit:** `P2024-XX-XX: FASE 4 — N códigos novos criados`

### Otimização para Janela de Contexto

Para economizar janela de contexto, as FASES 2-4 podem ser combinadas em um único commit quando o usuário aprova o garimpo completo.
